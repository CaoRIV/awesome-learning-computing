# OOP Knowledge Base

## Mục tiêu

Đây là knowledge base học Lập trình hướng đối tượng (**Object-Oriented Programming — OOP**) theo hướng hiểu bản chất, ra quyết định thiết kế và áp dụng vào hệ thống thực tế. C++ là ngôn ngữ chính; Java hoặc C# chỉ được dùng khi phép so sánh làm rõ khác biệt về mô hình đối tượng hoặc runtime.

Lộ trình kiến thức xuyên suốt:

> OOP → SOLID → Design Patterns → OOAD → Software Architecture → System Design

## Phạm vi hiện tại

Giai đoạn khởi tạo đã hoàn thành bộ khung học tập và kiến trúc nội dung. Các module kiến thức sẽ được viết tuần tự theo dependency graph; không viết Design Patterns hoặc system case study trước khi các prerequisite thiết kế đã được kiểm chứng.

## Nguyên tắc học

- **Deep Understanding > Memorization**: luôn truy nguyên vấn đề mà concept giải quyết.
- **Design Reasoning > Syntax**: code phải thể hiện quyết định thiết kế, không chỉ trình diễn cú pháp.
- **Practical Application > Definitions**: mỗi concept đi qua ví dụ, phản ví dụ, refactoring và bài tập.
- **Technical Accuracy > Brevity**: phân biệt language rule, design guideline và contextual trade-off.
- **Composition is the default candidate, not a dogma**: inheritance chỉ dùng khi substitutability thực sự đúng.
- **SOLID is diagnostic guidance, not a scoring system**: áp dụng theo cost of change và context.
